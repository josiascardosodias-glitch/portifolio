# Portfólio — Josias Dias Cardoso

Meu portfólio pessoal: um site de página única que reúne quem eu sou, o que estudo, as tecnologias com que trabalho e os projetos que venho construindo.

> 🔗 **Acesse o site:** https://josiasdias.vercel.app

## Sobre mim

Sou estudante de **Sistemas de Informação** na Faccat e programo há pouco mais de um ano. Comecei com Python, passei bastante tempo no desenvolvimento web e hoje venho incorporando inteligência artificial aos meus projetos. Meu objetivo é me tornar desenvolvedor full-stack e seguir evoluindo até o nível sênior.

## O que o site apresenta

- **Sobre mim** — uma apresentação rápida da minha trajetória.
- **Habilidades** — front-end, back-end, banco de dados e ferramentas do dia a dia.
- **Formação & Cursos** — graduação e cursos concluídos.
- **Projetos em destaque** — cada projeto com status, descrição, tecnologias e link para o repositório.

## Tecnologias do site

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4-06B6D4?logo=tailwindcss&logoColor=white)

O site nasceu em HTML, CSS e JavaScript puros e foi reconstruído em **React + TypeScript**, com **Vite** e **Tailwind CSS**. Nessa migração:

- cada seção virou um componente independente;
- todo o conteúdo (habilidades, cursos, projetos) passou a viver em arquivos de dados tipados, então adicionar um projeto novo é só acrescentar um item numa lista;
- o layout é responsivo, pensado primeiro para o celular;
- links de contato e redes sociais ficam em variáveis de ambiente, fora do código-fonte.
